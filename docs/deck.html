How we used the sponsors

No app code. The agent is Cline, with the right tool for each job.

Cline

The runtime
  • One skill file is the whole product
  • Setup is one script
  • cline schedule runs it every Monday
  • cline connect telegram puts it on your phone

Parallel

Search and deep research
  • Search and fetch verify every event date
  • Deep research on judges, sponsors and people (about 4.5 min a run)
  • Every claim in the Doc has a source link

Composio

Real actions, safely
  • Picks the right tool: Calendar, Gmail, Docs
  • Holds with no attendees, no invites, no Meet links
  • Gmail drafts only. It can't send
FOMO Bot3 / 5
Trust

Bounded, honest, and open.

Bounded

Creates Docs, Calendar holds and Gmail drafts only. Never sends, deletes or forwards email, and never invites anyone. Telegram is locked to one user.

Recovers from failure

Luma page with no date? It searches the web, or drops the event. It never invents a date, venue or speaker, and says what it did instead.

Open and easy to run

MIT licensed. Clone, run ./setup.sh, then cline "/fomo-bot ...". Run instructions are in the README.

What is simulated

The busy blocks on the demo calendar (study group, family dinner, gym) were added by us. Everything else is a live run on real accounts.
